# Rodham Kinya Karani Portfolio

A responsive Flutter web portfolio for Rodham Kinya Karani.

## Run locally

Install the Flutter SDK, then run:

```sh
flutter pub get
flutter run -d chrome
```

## Build and test

```sh
flutter test
flutter build web --release
```

The production website is generated in `build/web`.

## Content and privacy

The portfolio reflects the CV details supplied for Rodham Kinya Karani. Update `lib/main.dart` when his experience, education, skills, or contact information changes; replace `assets/rodham-karani-portrait.jpeg` to update the profile photo. Exact placement dates were not provided, so none are shown. Referee phone numbers are intentionally omitted from the public site; references are available upon request. No CV download is included because the source document is not stored in this workspace.
